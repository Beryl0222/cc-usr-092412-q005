# 更年期研究释义台

把“研究 → 临床释义 → 面向患者/医务人员的材料”纳入同一套只追加的领域事件服务：
研究版本、人群、终点、限制与统计结论分别留痕；每条公开主张声明所依赖的证据范围
与不适用情形；系统提示遗漏与过度外推，但只有研究方法人员确认解释、临床人员确认
边界（高风险人群另有额外复核）后，材料才能冻结进入指定使用场景。

## 领域规则

- **证据边界**（`src/boundaries.py`）：主张/措辞的人群、年龄、治疗窗口只能是研究
  的子集，终点必须被研究覆盖，研究排除条件不得丢弃，结论语气不得强于统计结论
  （相关不能写成因果或普遍建议），证据等级不得上调；涉及高风险人群必须显式提示。
  检查分为 `warnings`（可能遗漏/普遍化措辞/降级与随访提示）与 `errors`（硬违规，
  阻断冻结）。
- **签署门禁**（`src/service.py`）：`methodology` 确认解释 + `clinician` 确认边界，
  高风险内容再加 `extra_review`；签署可驳回，驳回或缺签不能冻结；冻结时绑定使用
  场景，发放前再次重检证据状态。
- **变化传播**（`flag_evidence`）：证据降级、撤稿、随访更新只影响引用该研究版本
  的材料——未冻结材料列入影响面（撤稿硬阻断后续冻结，降级/随访给出强制提示），
  已冻结未发放的不追溯改写但发放前必须人工处置，已发放版本不动并追加更正通知
  （`risk_handling` 风险处置 + 按发放名单跟踪接收确认）。
- **局部替换**（`replace_wording`）：科室措辞更新只产生新措辞修订，旧版本、旧签署
  与旧使用范围原样保留；新版本需重新签署才能进入场景。不同科室可有不同措辞，但
  共用同一证据边界，越界措辞无论走哪个科室都会被拒绝。
- **溯源与时点查询**：`trace(variant_id[, wording_revision])` 从一句公开表述追到
  研究限制、签署决定、使用场景、后续更正与回执；`explain_at(variant_id, as_of)`
  按时间回放，给出历史时点的解释（并标记证据变化是否发生在发放之后）。

事件一经接收，event_id、occurred_at、version 不原地改写；业务更正一律产生后继
事件。事件 id 由“聚合 id + 聚合内版本”确定性生成，调用方显式传入 occurred_at，
因此同输入在任意机器上回放结果一致。

## 目录

- `contracts/domain.schema.json`：事件信封、聚合类型与 12 种事件名称。
- `src/events.py`：事件名、角色与各事件必填载荷；`make_event` 构造与信封校验。
- `src/boundaries.py`：证据范围/结论语气/高风险规则。
- `src/store.py`：只追加事件存储（唯一 id、聚合版本递增、事件-聚合匹配）。
- `src/projection.py`：事件流折叠为当前状态或历史时点状态。
- `src/service.py`：`TranslationService` 全部用例与溯源查询。
- `data/sample.json`：一条合规 CLAIM_MAPPED 联调样例。
- `tests/`：边界单测、工作流门禁，以及撤稿传播/局部替换/历史时点的确定性场景。

## 本地检查

```bash
python3 -m unittest discover -s tests
python3 -m compileall -q src tests
```

可在单个 Linux 应用容器内执行，不需要外部服务。跨 `PYTHONHASHSEED` 重跑结果一致。
