# 更年期研究释义台

本仓库保存该服务的领域资料、事件约定与参考实现，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/validator.py`：校验事件信封的基础字段、枚举取值与时间格式（枚举与契约同源）。
- `src/events.py`：事件信封与只增日志；事件接收后标识、发生时间和版本不被原地改写。
- `src/state.py`：由事件日志重放出的读模型；当前态与历史时点共用同一段重放逻辑。
- `src/checks.py`：措辞体检，确定性提示遗漏与过度外推（只提示，不裁断）。
- `src/service.py`：命令侧服务——研究登记、主张映射、材料生命周期、证据更新传播。
- `src/queries.py`：公开表述溯源、历史时点解释、待确认接收清单。
- `tests/`：验证样例、基础约定与服务行为。

## 服务主线

1. **研究登记**：研究版本、人群、终点、限制条件、统计结论分别留痕；同一研究再次登记产生新版本，旧版本保留。
2. **主张映射**：每条面向患者或医务人员的主张声明证据范围（终点、人群、时间窗）与不适用情形，并锚定映射时的研究版本。
3. **材料版本**：科室起草措辞 → 系统体检提示遗漏与过度外推 → 方法学确认解释、临床确认边界（高风险人群内容另需复核）→ 批准进入指定使用场景 → 发放即冻结。不同科室可用不同措辞，但引用同一主张、同一证据边界；修订后签署与体检失效，须重新进行。
4. **证据传播**：降级、撤稿、随访更新只标记引用它的未冻结材料（待修订）；已发放版本不被改写，追加风险处置（更正通知）并要求接收方确认。
5. **溯源查询**：从一句公开表述追到研究限制、签署决定、使用范围和后续更正；可按历史时点重建当时的解释。

## 领域边界

当前资料围绕研究限制、主张映射和临床边界整理。事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

## 本地检查

```bash
python3 -m unittest discover -s tests
```

## 测试与构建

测试命令：

```bash
python3 -m unittest discover -s tests
```

编译或构建命令：

```bash
python3 -m compileall -q src tests
```

这些命令可在单个 Linux 应用容器内执行，不需要另行启动外部服务。

确定性测试覆盖的关键场景：撤稿传播（`tests/test_evidence_propagation.py`）、
局部替换（`tests/test_partial_replacement.py`）、历史时点解释与表述溯源
（`tests/test_traceability.py`）。
